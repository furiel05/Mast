# Chrome Web Store 掲載情報

Chrome Web Store のデベロッパー ダッシュボードに入力する内容をまとめる。
アップロードする zip は `npm run zip`、画像は `npm run store-images` で作る（`.output/` に出力される）。

## 説明文

```
YouTube を見てよい時間を、あらかじめ決めた「予約枠」の中だけにする拡張機能です。

■ できること
・曜日ごとに、見てよい時間帯（例：20:00〜23:00）と、1日に見てよい時間の上限（例：1時間まで）を決められます。どちらか片方だけでも、見ない日にすることもできます
・時刻はホイールを回して選びます。設定の意味は「20:00〜23:00 のうち、合計1時間まで見られます」のように文章でも表示されます
・予約枠の外で YouTube を開くと、ブロック画面と次に見られる時刻を表示します。見ている途中で枠が終わったときも切り替わります
・他のサイトに埋め込まれた YouTube も対象です。YouTube Music は対象外です
・1日の区切りは朝4時。夜ふかしした深夜も「その日の夜」として扱います

■ 衝動的に設定を変えさせない仕組み
・予約枠を狭める変更は、すぐに反映されます
・広げる変更には、スマホの認証アプリ（Google Authenticator など）の6桁のコードが必要で、反映されるのは申請から24時間後です。いつ申請しても、その日のうちには見られません

■ 複数のパソコンで
・予約枠と視聴時間は、Chrome の同期で同じ Google アカウントのパソコンどうしで共有されます（Chrome の同期で「拡張機能」をオンにしてください）

■ プライバシー
・データは開発者にも第三者にも送りません。YouTube では動画が再生中かどうかだけを見ていて、何を見たかは記録しません
```

## 単一用途の説明

```
YouTube の視聴を、利用者が決めた時間帯と1日の合計時間の中だけに制限します。
```

## 権限が必要な理由

| 権限 | 理由 |
| --- | --- |
| `storage` | 予約枠の設定、承認コードの秘密鍵、日ごとの視聴時間を保存し、Chrome の同期で利用者のほかのパソコンと共有するため |
| `alarms` | 予約枠の始まりと終わり、1日の視聴時間を使い切る時刻に、YouTube のブロックを切り替えるため |
| `declarativeNetRequest` | 予約枠の外で、YouTube のページをブロック画面に置き換えるため |
| ホスト権限（youtube.com、youtube-nocookie.com、youtu.be） | 上のブロック画面への置き換えと、YouTube の動画が再生中かどうかを確かめて視聴時間を数えるため |

## リモートコード

使用していない（すべてのコードは zip に含まれる）。

## データの使用（プライバシーへの取り組み）

開発者にデータは送らないが、保存しているデータの種類に合わせて、控えめに次を申告する。

- 収集するデータ：「認証情報」（承認コードの秘密鍵）、「ユーザーのアクティビティ」（日ごとの視聴時間）
- 次の3つに同意する
  - 承認されている用途以外で、第三者に販売・転送しない
  - 拡張機能の単一用途と関係のない目的で、使用・転送しない
  - 信用力の判定や貸付の目的で、使用・転送しない

## 公開の手順

1. `package.json` の `version` を上げる（ストアは同じバージョンの zip を受け付けない）
2. `npm run zip` で `.output/mast-<version>-chrome.zip` を作る
3. `npm run store-images` でスクリーンショットとプロモーション タイルを作る
4. デベロッパー ダッシュボードで zip をアップロードし、この文書の内容を入力して審査に出す

## 公開前の実機での確認

自動テストでは確かめられないもの。WindowsとMacの両方で、ストア版（または `npm run zip` の zip を読み込んだもの）で確かめる。

- [ ] インストールすると設定画面が開く
- [ ] スマホの認証アプリ（Google Authenticator など）でQRコードを読み取り、確認コードで設定が済む
- [ ] 広げる変更を申請すると、24時間後に反映される
- [ ] もう1台のパソコンに、予約枠・予約中の変更・承認コードの設定が同期される
- [ ] 本物のYouTubeで、通常の動画・ショート・ライブの再生時間が数えられる。サムネイルのプレビューは数えられない
- [ ] 他のサイトに埋め込まれたYouTubeの再生時間も数えられ、見られない時間にはブロックされる
- [ ] パソコンのスリープから戻ったとき、見られない時間ならブロックされる
